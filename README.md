# 나비와 깊은 물

깊은 물이라야 큰 고기가 난다. 에니어그램 7번(낙천가) 이야기를 바탕으로, 작은 즐거움과 깊은 즐거움 사이에서 고르는 **30초 깊은 물 낚시 게임**, 갓 사러 갔다가 망건 사지 않도록 돕는 **오늘의 갓 집중 타이머(나중 상자)**, 1분 **활력 계기판**을 담은 앱입니다. 「에니어그램 7번 낙천가」 [Psyche 09] 부록이며, 파일 하나(`index.html`)로 인터넷 없이 동작합니다.

> **바로 하기: https://woojuntaek-lgtm.github.io/butterfly-deep/**

## 특징
- 🎣 깊은 물 낚시: 얕은 물 작은 물고기(톡, +1) vs 깊은 물 큰 고기(꾹 3초, +12), 날아다니는 나비, 결과별 한 줄 메시지·최고 기록
- 🎩 오늘의 갓: 한 가지 목표 + 10/15/25/45분 타이머, 떠오른 다른 생각은 "나중 상자"에 맡기기, 누적 기록
- 🌋 활력 계기판: 12문장 1~5점 → 활력·탐닉·절제와 상태(깊은 물의 나비 / 망건 쇼핑 중 / 속이 빈 화산 / 차분한 숲 / 잠시 흐린 하늘), 맞춤 처방
- 🦋 7번 한눈에: 사고형 안의 자리, 동양 수리(火·화산), 나비·그린, 두려움과 회피, 절제와 탐닉, 날개, 스트레스·성장 방향

성찰을 돕는 참고용이며 심리검사나 전문 상담을 대신하지 않습니다. 입력 내용은 기기 밖으로 나가지 않습니다.
